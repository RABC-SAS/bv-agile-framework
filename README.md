# bv-agile-framework
Bigview agile framework implementation for `RABC-SAS/bv-agile-framework`.

- Seven typed/untyped issue forms and a report-only validation Action.
- Idempotent, dry-run-first organization, project and smoke-test CLI.
- Configuration: `.github/planning/hierarchy.yml`.

See [execution commands and live setup status](IMPLEMENTATION_GUIDE.md).
Run local tests with `node --test tests/framework.test.mjs` (Node.js 22+, Ruby and `gh`).
